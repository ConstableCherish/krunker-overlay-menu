## 🧩 About

**Krunker Overlay Menu** is a curated list of Krunker open-source tools:

- **Overlays** — on-screen helpers, layout notes, crosshair viewer, minimap notes
- **Quality-of-Life Helpers** — class catalog, loadout notes, overlay notes
- **Research Notes** — map layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Match Helpers
- Crosshair Overlay — custom crosshair layouts for study
- Minimap Notes — visualize map routes and spawn points
- Replay Notes — record and review match runs
- FPS Counter — track frame stability during study (0.1x to 5x)

### 🎨 Catalog & Loadouts
- Class Catalog — browse classes, weapons, skins, camos
- Custom Loadout Notes — organize player presets
- Hit Marker Notes — improved feedback visibility

### 🏋️ Practice Layout
- Training Mode Notes — segment study on any layout
- Movement Notes — review bunnyhop and slide paths
- Input Buffer Notes — chain complex maneuvers in practice
